# Template Portofolio Web Developer

## Struktur Folder
- `index.html`: Halaman utama portofolio
- `style.css`: Pengaturan desain, warna, dan responsivitas
- `script.js`: Fitur dark/light mode dan animasi scroll
- `assets/foto.jpg`: Simpan foto profil kamu di sini
- `assets/projects/`: Simpan gambar screenshot proyek (`proyek1.jpg`, `proyek2.jpg`, `proyek3.jpg`) di sini

## Cara Penggunaan
1. Ganti semua teks placeholder (`Nama Kamu`, `username`, deskripsi, dan link) di file `index.html`.
2. Masukkan foto profil dan gambar proyek ke dalam folder `assets/`.
3. Upload seluruh isi folder ini ke repository GitHub bernama `username.github.io` dan aktifkan GitHub Pages di **Settings > Pages**.
